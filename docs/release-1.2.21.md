# v1.2.21

视频任务限额调整为每用户同时最多20个、滚动60秒内最多新建50个、全站同时最多500个。网页和API共用限额，前端支持已有任务时继续提交，并显示当前占用名额。

- 并发与频率在预扣前加锁复核，超过限额返回429，不额外扣分。失败任务释放并发但仍计入该分钟新建次数；同业务编号重放继续复用原任务。
- 历史列表提供独立的活跃任务计数，不因分页漏算旧任务；数据库增加统计索引。待核对任务仍计入并发。
- 视频创建收到HTTP502时按本站政策失败退款，不自动重新提交。退款账本保持幂等，重启恢复不会重复退款。502可能已被上游受理，相关费用由本站承担。
- 已受理任务查询/下载遇到502继续重试原任务；其他不确定创建结果仍保留待核对。图片生成规则及现有模型价格不变。
- 工作室、后台说明及客户API文档同步更新，GitHub CI增加前端契约回归。

验证覆盖20/50/500边界、多线程竞争最后名额、滚动时间窗、分页外任务计数、业务编号重放、502退款和重启幂等；使用隔离数据和mock，不提交真实付费生成。
