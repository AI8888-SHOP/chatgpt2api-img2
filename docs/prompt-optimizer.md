# 独立 AI 提示词优化

管理员在 `/admin/settings` 的「AI 提示词优化 · 独立 API」填写 Base URL（例如 `https://api.example.com/v1`）、API Key 和文本模型，然后保存并启用。凭据仅存服务端配置，读取配置不会回显密钥；留空保留原密钥，勾选清除后保存才会删除。真实 `config.json` 不应提交 Git。

使用 OpenAI 兼容的 `POST /chat/completions`。输出限制参数默认 `max_completion_tokens`，可切换为兼容上游的 `max_tokens`。按 OpenAI 官方 token 文档，前者包含非可见的推理 token；应选用适合短文本改写的模型并按其实际协议设置。参考：<https://developers.openai.com/api/docs/guides/token-counting>。本地输入限制包含固定系统指令、JSON 包装和消息开销预留；不同厂商的 tokenizer 可能不同，不能将本地预算视为账单精确计量。

默认关闭；未配置时返回 503。启用后不再使用 Free 账号池，也不在 API 失败时返回固定拼接文本。请求失败会明确报错。

## 防滥用

- 只接受有效网页登录会话（`usr_`），拒绝 `uak_` 用户 API Key 和管理员密钥；实际身份还须通过数据库会话校验。
- 请求只能包含 `prompt`；为兼容旧网页，可带 `model: auto`。额外字段、模型选择、消息列表、系统指令和工具均被拒绝。上游固定两条消息、单条文本输出，不提供通用聊天透传。
- 输入 HTTP body 上限 64 KiB、文本上限 12000 字符，再按 token 拒绝超限输入。输出同时设置上游生成上限与本地返回长度上限，响应体超过 128 KiB 拒绝。
- 默认每用户 3 RPM、30 次/日、30000 token 预算/日、并发 1；输入上限 2048 token、输出 512 token。
- 默认全站 60 RPM、1000 次/日、1000000 token 预算/日、并发 4；超时 30 秒。
- 默认账号至少注册 600 秒且余额至少 1 积分；这是使用门槛，不扣积分。可在后台修改。
- RPM 使用滚动 60 秒；每日额度 UTC 零点重置。按账号 ID 计数，换登录 token 不重置。每次准入按输入 token 加最大输出 token 计预算，失败仍计次且不退预算，避免失败重试刷上游。
- `data/prompt_optimizer_limits.db` 使用 SQLite 原子事务保留最近两天准入记录（不存提示词或密钥）；同数据目录的多个进程共享限额，重启不会清零。多主机应共享独立集中式限流存储，不能各自使用数据库副本。
- 达限返回 429 与 `Retry-After`；上游错误统一脱敏，不返回响应体、密钥或内部地址。不自动重试。并发租约在异常退出后超时释放；上游在客户端断开后仍可能继续计费。

网页会话同样可以被脚本调用，固定提示词也不是可靠的语义安全边界。额度和 token 限额用于限制可消耗的资源；多账号滥用还需结合注册、邀请、邮箱验证策略以及 API 提供商的消费限额。

## 验证

`python -m unittest discover -s tests -p 'test_prompt_optimizer*.py' -v` 使用模拟上游和临时限流数据库，不消耗真实 API 额度。
