# 1.1.0 — 双界面试用

- A 雾白靛蓝：左侧对话历史，结果下方输入，同一对话连续修改。
- B 石墨青绿：中央结果画布，右侧创作面板，按轮次浏览。
- 共用真实绘图、参考图、遮罩、优化提示词和任务逻辑；切换不会重新挂载输入组件。
- 前台、后台、登录页使用统一简约配色；两套方案均支持浅色、深色与手机。
- 顶部 A/B 随时切换；“投票”入口提供 A / B / 都可以，可修改或撤回。
- 首次按账号稳定哈希近似均分。偏好存服务端，换设备、重新登录仍保留；本地存储只辅助显示，不充当统计来源。
- 后台 `/admin/ui-trial/` 展示初始分组、体验人数、当前选择、明确偏好和近 7 天活跃用户。所有投票按账号去重，默认分组和切换不算偏好票。
- 先体验两套后才允许投票；仅接受登录会话，不接受用户 API Key。统计接口仅管理员可访问。
- 一账号一条试用状态；不额外采集提示词、图片或逐次点击日志。不额外收费，不更改原有额度、API 配置或反滥用限制。
- 两套均持续保留，不设置自动结束或自动胜出规则，后续人工根据样本反馈决策。

## 数据与回滚

新增 `users.db` 内的 `user_ui_trial` 表，外键关联用户；不改写原有用户或会话表。回滚到 1.0.2 可直接使用原数据，新增表会保留供之后使用。

## 验证

- TypeScript 独立检查与 Next 静态构建。
- `tests/test_ui_trial.py`、`tests/test_ui_trial_api.py`：去重、并发、账号隔离、权限、会话轮换、无额外扣费。
- `web/tests/ui-regression.cjs`：通过 `UI_DESIGN=a/b` 分别测试两套布局、手机、明暗模式和已有交互。
- `web/tests/ui-trial.cjs`：切换保留草稿与参考图、优化中切换、轮次、投票修改/撤回、重载恢复、失败回显和后台统计。
- 浏览器测试拦截所有应用 API，不使用真实用户数据，也不发起真实图像或优化调用。
