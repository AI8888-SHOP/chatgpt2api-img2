# 模型独立积分

后台图片模型每项可填写 `generate_price`（文生图积分/张）、`edit_price`（图生图积分/张）。视频模型可填写 `price_480p`、`price_720p`、`price_1080p`（积分/秒）。所有价格为1–10000整数，未填则沿用原有全局默认价，兼容已部署配置。不同模型 ID 独立定价，同一模型的多个渠道使用该模型价格。

前端图片模型下拉显示两种单价，视频下拉显示已开放分辨率的每秒单价，预计积分按所选模型、时长与清晰度计算。服务端自行读取配置，不接受客户端报价。图片任务保留提交时单价，视频任务保留提交时总价；后台改价不影响已经提交的任务。生成失败仍按原预扣金额退回。

未在图片目录配置的兼容 API 模型沿用全局默认价格；`auto` 使用默认图片模型价格。模型别名应作为独立模型 ID 配置价格。
