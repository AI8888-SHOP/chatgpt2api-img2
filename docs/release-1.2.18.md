# v1.2.18

- 视频模型支持按秒或按次计费，按清晰度设置价格；旧配置默认按秒，原任务保留原金额结算。
- 后台可设置固定可选时长，前端随模型切换，API 同样校验；Image2Pro 保留协议能力档位。
- 图片结果新增图生视频入口，将选中图片带入独立视频工作室，用户确认后才生成。移除画图页内重复的图片/视频切换。
- API 文档采用独立目录、响应式布局和可复制代码示例。

按次计费需明确填写各已开放清晰度价格。视频参考图支持 PNG/JPEG/WebP，最多 5 MB；不自动转换 GIF。图片带入仅短暂保存在当前页面内存，刷新后需重新选择。

保留生产模型、价格、余额和数据，不自动启用新模型，不进行额外付费生成。上游 GIF、Veo/Omni 能力仍以实际渠道确认结果为准。
