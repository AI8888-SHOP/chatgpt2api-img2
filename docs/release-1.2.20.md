# v1.2.20

修复图片 API 的模型计费、输入校验、重复提交和错误信息暴露问题，更新自助充值入口。

- 网页和 API Key 统一使用后台开放的图片模型及对应生成、编辑价格，模型名规范化后计费。
- 参考图片不再接受用户提供的外部 URL。使用文件上传或受限 Base64；视频参考图可上传后使用本人 asset_id。图片文件每张最多 25 MiB，JSON 内联图片每张最多 10 MiB，合计最多 60 MiB、最多 10 张；视频素材按原模型及上传限制校验。
- 不确定的图片生成失败不自动重新提交。网络异常、408、5xx 或未能确认成品时保留预扣待核对；重启和过期清理不会自动退款。明确拒绝依原流程幂等退款，同任务恢复查询复用原预扣。
- 对用户隐藏图片上游错误正文；历史任务错误同样通过安全文案展示。多图未知结果需核对整个批次，避免按单图恢复误退其他图片费用。
- 自助充值使用新的购买链接，积分兑换表单从个人中心移至充值页，API 文档同步更新上传要求。

验证：隔离环境全量 241 项回归通过；最后调整后相关 52 项回归及 TypeScript 检查通过。GitHub CI 将对发布提交运行完整测试并构建镜像。验证未提交真实付费生成，未修改生产价格和用户余额。

兼容性：此前发送外部图片 URL 的客户端需要改用上传文件、Base64 或视频素材 asset_id。提交结果未知的请求需要核对后结算，不应自动再次创建。
