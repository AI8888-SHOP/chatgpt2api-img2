# 1.2.7 · 单渠道多模型

- 生图上游配置新增 `models` 数组，同一个渠道可复用 Base URL、API Key 和连接设置接入多款模型。
- 请求按模型筛选支持该模型的已启用渠道，再在渠道之间轮询；实际请求模型会原样传给上游。
- 旧配置中的单值 `model` 自动兼容为一个模型，不需要手动迁移；设置页保存后使用新的多模型格式。
- 前端模型开放校验、图片生成、编辑、后台任务和失败重试均支持同渠道多模型。
- API Key、Base URL 仍只保存在后台配置，不出现在公开 `/app-config` 或生图客户端响应中。

- 完整后端测试、TypeScript、Next 生产构建及后台设置页面检查通过。
