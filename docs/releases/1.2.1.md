# 1.2.1 · API 文档工作室与静态文件安全修复

包含 1.2.0 的完整 PPT / PSD API 工作室功能。1.2.0 候选版未部署，正式部署使用 1.2.1。

- 修复旧版静态资源路由的路径越界读取问题：规范化路径、限制真实文件位于静态目录、拒绝父目录访问，阻止外部符号链接。
- 新增 GET / HEAD 编码路径和符号链接回归测试，使用隔离的合成标记文件，不读取生产密钥。
- 其余功能、配置、限制与文件格式说明见 1.2.0 发布说明和文档工作室指南。
- 升级保留现有用户、积分、绘图会话和数据卷；生产 PSD 价格沿用原配置。

镜像：ghcr.io/ai8888-shop/chatgpt2api:1.2.1

安全建议：旧版部署若直接暴露服务端口，应评估并轮换旧凭据。发现该漏洞不代表已确认发生泄露；本次漏洞验证未通过该路径读取密钥。
