# 1.2.5 · 后台 UTC+8 与前端模型管理

## 变化

- 后台时间统一为北京时间 UTC+8，不受服务器或浏览器所在时区影响。覆盖用量、审计、用户、兑换码、缓存、账号恢复时间、注册和导入记录、界面试用统计。
- 兑换码 CSV 标注 UTC+8，创建、过期、兑换时间使用同一格式；用量统计按 UTC+8 日期归属。存储的 Unix 时间戳、限额周期和任务调度不变。
- 后台设置新增“前端可用模型”：模型 ID、显示名称、启停、上下排序和默认模型。`image_models` 按数组顺序显示，`default_image_model` 指定默认项。
- 绘图页面从 `/app-config` 获取模型，重新进入或窗口恢复焦点时更新。公开响应仅含模型 ID、名称和默认项，不含连接或密钥；禁止缓存。
- 无可用模型或配置加载失败时禁止生成。复用旧会话时保留历史模型信息；原模型停用后提示并切换当前默认项。
- 网页生图/编辑入口在扣费、创建任务之前验证开放模型和上游可用性。停用全部上游后不再自动重启禁用路由，也不悄悄落回账号通道。

## 配置与兼容

- 未设置新字段的旧配置继续使用 `gpt-image-2`、`grok-imagine-image`，默认前者；显式空列表表示关闭前端生成。
- 自定义模型 ID 必须与已接入且启用的生图上游一致；前端列表本身不会创建上游能力。重复 ID、非法默认项和超限配置在保存时拒绝。
- 现有 `image_default_model_slug` 是账号通道内部模型，与新增前端默认项独立。
- 此列表管理绘图工作台。提示词优化和 PPT / PSD 使用各自后台配置；Chat / Responses 兼容接口及 `/v1/models` 保持原协议。
- 无数据库迁移。升级前备份配置和数据，等待活动任务完成，仅更新 app；可回滚 1.2.4。
