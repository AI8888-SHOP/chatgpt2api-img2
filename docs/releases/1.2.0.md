# 1.2.0 · API PPT / PSD 文档工作室

## 新增

- 接入后台配置的视觉 / 思考 API，不占用 ChatGPT 账号池。支持复用优化器连接或独立地址、密钥、模型。
- PPT 四套真实模板预览，文字需求 → AI 大纲 → 用户修改和确认价格 → 原生可编辑 PPTX、实际逐页预览及 PDF / 素材包。
- PSD 视觉引导的原图像素拆分，中文命名图层、原位置、透明素材、图层蒙版与合成核对；提供 PSD、PNG ZIP 和预览。
- 独立后台配置：单用户 RPM、输入 / 输出 / 思考 Token、每日预算、账号门槛、并发与队列、超时、文件 / 存储限额、价格和保留期。
- 持久任务队列、原子预扣 / 退款、重复提交幂等、按用户隔离的私有下载。

## 兼容与边界

- 保留原有用户、余额、绘图会话、旧任务历史和 A/B 界面试用。
- 旧版文件下载现在需要所属用户登录；不再公开匿名直链。
- PSD 文字是像素文字，不是原生字体层；平面图无法恢复隐藏图层或原始遮挡像素，近似背景修补会明确标注。复杂边缘需要人工核对。
- 上游负责结构化分析，本机受控程序生成文件；不执行 AI 返回的代码或任意工具 / URL。
- 新安装默认关闭，升级站点需后台启用。PSD 价格应沿用原站点，PPT 默认 1 积分 / 页，均可调整。

## 验证

- 后端单元和 HTTP 测试覆盖预算、认证、密钥、幂等、退款、队列、文件结构与真实预览。
- 实际上游 + HTTP 确认 + 后台队列 + 受限渲染进程已跑通 PPT 和 PSD 合成样本。
- 工作室 54 项浏览器检查、既有双 UI 54 项回归，覆盖手机 / 桌面和 A/B 明暗模式。
- 发布流水线先跑后端测试及 TypeScript 检查，再编译 linux/amd64 与 linux/arm64 镜像。
