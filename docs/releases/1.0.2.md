# 1.0.2

## UI 与交互修复

- 修复静态页面尾斜杠导致历史记录入口失效、导航选中错误以及登录页多余导航。
- 改善手机、平板与桌面工作区布局，减少空白占位，避免按钮挤压换行；常见桌面尺寸无需滚动即可看到生成操作。
- 菜单与历史抽屉支持 Esc 关闭、焦点管理、背景滚动锁定；修复图片预览背景关闭和索引边界。
- 中文输入法确认候选字不再误提交生成任务。
- 提示词优化不再覆盖请求期间的新输入或新会话草稿，并防止重复优化请求。
- 修复重复选择参考图、触屏移除/遮罩按钮可见性、文件与预览状态不同步及控件焦点被抢。
- 改善深色模式的遮罩、禁用按钮和提示浮层，移除用户页面中的内部开发说明。

## 验证

- TypeScript 检查、3 项会话分组测试、前端生产构建通过。
- 新增 Chromium UI 回归脚本，六组手机/平板/桌面尺寸共 42 项检查通过，覆盖真实页面交互和静态导出产物。
- 浏览器测试使用模拟 API，不修改生产数据、不调用付费上游。尚未覆盖 Safari、实体手机软键盘或真实第三方生成。

## Docker 与升级

镜像：`ghcr.io/ai8888-shop/chatgpt2api:1.0.2`

构建架构：`linux/amd64`、`linux/arm64`。

只修改前端行为，不修改计费、权限、数据库结构或后台配置。升级前备份配置和数据，保留 `config.json` 与 `data/` 挂载。升级后如仍显示旧界面，请强制刷新页面。
