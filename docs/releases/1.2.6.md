# 1.2.6 · 用量记录显示上游

- 后台用量明细、首页最近调用新增“上游”列，首页“查看用量”链接直达用量页。
- 图片生成、编辑、后台任务与恢复轮询保存调用时的上游名称。外部图片 API 使用后台配置名称；失败重试记录最后尝试的上游，后续改名不改变旧记录。
- Chat / Responses 兼容接口区分 ChatGPT 账号池、GPTFree 账号池及本地缓存 / 请求合并，覆盖流式和非流式调用。提示词优化标记“提示词优化独立 API”。
- 调用前失败显示“未调用上游”；旧版本未保存上游的记录显示“未记录”，不按当前配置猜测历史。旧 PSD 提交记录注明账号池任务提交阶段。
- 上游字段仅保存名称，不添加地址、API Key 或 Token；不改变客户端生成结果和计费逻辑。PPT / PSD 工作室继续使用独立任务统计。
