# 1.0.1

## 新增

- 复用图像输入后可在原对话继续，新轮次保留此前提示词和图片；历史列表按对话分组，并提供新建对话入口。
- 提示词优化支持独立的 OpenAI 兼容 Chat Completions API。在后台系统设置中配置 Base URL、密钥、文本模型、token 参数和本地计数器。
- 后端执行每用户 RPM、每日次数、每日 token 预算和并发限制，同时提供全站限额、请求超时、最低积分余额及新账号等待时间。
- 限额按用户账号持久化到 SQLite，换登录会话或服务重启不会清零。拒绝用户 API Key 调用，拒绝请求中指定模型、系统提示词和工具。
- 优化上游失败时明确报错，不再用固定文本回退。密钥不回显，上游错误脱敏。

## 升级说明

- 独立提示词优化默认关闭。升级后需到后台填写真实 API 地址（含 /v1）、密钥和模型并启用。原 Free 账号池不再用于此按钮。
- 默认每用户 3 RPM、30 次/日、并发 1；每次输入上限 2048 token（含固定指令），输出上限 512 token。全部可在后台调整。
- 每日预算按每次输入加最大输出预留，失败也计次、不退预算，UTC 零点重置。第三方模型分词可能与本地计数器不同。
- 保留 config.json 与 data/ 持久化挂载。若旧部署挂载 services/config.py 等单个源码文件覆盖镜像，需要同步更新或移除旧代码挂载，以免覆盖新版实现。升级前备份配置及 data/。
- 登录会话仍可被脚本使用；用途约束与资源限额用于限制滥用成本，并不保证接口只能通过网页点击调用。
