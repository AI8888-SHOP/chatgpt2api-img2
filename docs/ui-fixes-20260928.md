# UI 修复与回归记录（2026-09-28）

本次只修改前端，不修改接口计费、权限、数据库结构或后台配置。

## 已修复

- 静态导出路径带尾斜杠时，历史记录入口不响应、导航选中状态错误、登录页意外显示工作台导航。
- 菜单/历史抽屉缺少 Esc、焦点限制与背景滚动锁定；改用 Radix 模态 Portal。
- 平板工作区使用三行固定网格但只显示两块内容；改为流式排列，仅宽屏保留三栏工作台。
- 手机新对话空白结果区占据过多高度；空状态自适应，结果区与输入区保留各自滚动。
- 图片轮次更新使用 scrollIntoView 会带动整个页面；现在只滚动结果面板。
- 中文输入法确认候选字的 Enter 会提交生成任务；增加 composition 与 keyCode 229 防护。
- AI 优化期间修改输入或切换会话，旧响应覆盖新草稿；使用草稿修订号丢弃过期响应，并防止重复优化。
- 文件选择后 input 未清空，无法重新选择同一文件；改为选择后清空，并原子更新参考文件与预览。
- 手机参考图的移除/遮罩按钮只在 hover 可见；触屏默认显示，桌面也支持键盘焦点显示。
- 输入区域父元素抢占子控件焦点；移除全区域点击强制聚焦逻辑。
- 窄输入列操作按钮挤压换行；改为等宽双按钮并缩短文案，添加输入控件可访问名称。
- 图片预览背景无法点击关闭、图片列表变化时索引失效；修复背景点击和索引边界。
- 深色模式的背景遮罩被通用样式误染为强调色，禁用按钮和提示浮层对比度不一致。
- 删除正式页面中关于“开发端”和“上线到 3020”的内部说明。

## 验证

`web/tests/ui-regression.cjs` 使用真实 Chromium 页面交互，覆盖手机、平板、桌面六组尺寸，包含浅色/深色截图、历史、多轮复用、中文输入法、优化响应竞争、重复选图、输出格式选择、登录页和后台设置页。

所有应用 API 请求均由浏览器拦截并返回合成测试数据，不使用真实账号、不修改生产数据、不发起付费图片生成或 AI 调用。`AUDIT_ONLY=1` 可在旧版本记录失败而继续检查；默认模式任一断言失败退出非零。

运行（需已安装 Playwright 与 Chromium）：

```sh
cd web
npx tsc --noEmit
node --test tests/image-threads.test.cjs
npm run build
PLAYWRIGHT_PATH=/path/to/playwright BASE_URL=http://127.0.0.1:3032 node tests/ui-regression.cjs
```

浏览器回归也必须在 `web/out` 的静态导出产物上执行，不能只测试开发服务器。未覆盖真实第三方生成、Safari 或实体手机软键盘。
