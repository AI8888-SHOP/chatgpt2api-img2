# 个人预设与图生图原图

每位用户可在图片、视频编辑区的“我的预设提示词”中新增、编辑、删除或填入个人预设。每人最多 15 条，名称最多 60 字，内容最多 8000 字。数据存储在服务器用户数据库中，与管理员公共快捷提示词独立。后端按当前登录用户隔离，并用数据库事务保证并发提交不超过上限。

`/v1/user/prompt-presets` 提供 GET、POST；`/{id}` 提供 PUT、DELETE。所有接口要求用户身份，不接受客户端指定所属用户。

同步与后台图生图任务在调用上游前，将上传文件的原始字节保存在 `data/usage_reference_images`，按提交顺序关联用量记录。生成失败也记录原图；续查任务沿用原图关联。该目录不通过静态文件服务公开，备份时应与用户数据库、用量日志一起备份。

管理员在“用量记录”点击“查看原图”可预览。预览接口要求管理员鉴权，并重新编码为 JPEG，避免将上传内容作为主动网页内容返回。原始文件保持不变，预览最大 1600 像素。此前未留存原图的记录显示“原图未记录”。

用量日志上限为最近 10000 条，超出上限或管理员清理旧记录时，会删除不再被其他用量记录引用的关联原图。进程在保存原图后、写入用量记录前异常退出可能留下孤立文件；这些文件无法经预览接口访问，当前不自动清扫孤立文件。
